# Systems

The browser recreations are original programs, not dumps, and do not share ids with consoles; [arcade/README.md](../../arcade/README.md#games) lists every game the arcade ships. The browser console loader (`#/emulate`) uses the same console ids with user-supplied dumps.

## Enable an extra emulator

```sh
./bin/retropi systems enable wonderswan
./bin/retropi cores install --system wonderswan
./bin/retropi build
```
