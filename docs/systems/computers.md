# Computers

> DOS, the Commodore 64 and Amiga, and ScummVM: the microcomputers and the adventure runtime that outlived several of them.

## MS-DOS (`dos`)

1981 floppy / directory. Alias: `pc`. DOSBox-style libretro core via the emulate manifest. Catalog accepts DOS as a shelf platform for boxed PC games.

## Commodore 64 (`c64`)

1982 floppy / tape / cart. VICE x64 / x64sc. Extensions include `.d64`, `.t64`, `.prg`, `.crt`, `.tap`.

## Amiga (`amiga`)

1985 floppy / hardfile / CD. PUAE. Kickstart ROMs are not supplied; dump them from Amiga hardware you own. Aliases: `a500`, `a1200`. Enable when you have Kickstart and a library of `.adf` / `.lha`.

## ScummVM (`scummvm`)

1987– directory. LucasArts, Sierra, and other adventure engines. Each game folder needs a `.scummvm` stub the frontend can launch. Alias: `scumm`.
